# data/

- `binding_declaration.json` — the exact `LineEntry` kwargs for line_set admission (prepared input; line_set itself is not edited here).
- `envelopes/` — witness envelopes prepared for the shared witness register (the register itself is not edited here).
- `fixtures/` — maintained synthetic declarations for the complete current artifact cohort.
- `reports/` and `snapshots/` — immutable SHA-256-addressed records; retain all prior bytes when generating current artifacts.
- `claim_ledger.yaml` — the claim register of record (executable and refused claims).
- `formalism_claim_ledger.json` — GENERATED by `scripts/gen_formalism_ledger.py`; never hand-edit.
- `AGENTS.md` — working notes for this directory.

Run `uv run python -m silver_line.artifacts` to update current prepared envelopes
and create new content addresses; `--check` checks the current cohort without
writing. Historical reports and snapshots retain their original vocabulary,
including `custodian_acknowledgement` and `drift_acknowledgement`. Current
required labels use `custodian_acknowledgment` and `drift_acknowledgment`;
the historical spellings are not parser aliases. Published release packets
and dated review evidence are history, not current execution results.
