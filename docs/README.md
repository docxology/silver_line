# Silver Line documentation

Silver Line reads declared provision for what is kept, entrusted, or allowed to
lapse. A reading records declaration coverage and gaps at its stated review
date. The [claim boundaries](claim_boundaries.md) companion explains what this
evidence establishes.

| Task | Guide |
| --- | --- |
| Read a succession declaration or declare a release | [Usage](usage.md) |
| Interpret, archive, or replay a verdict | [Report schema and migration](report-schema.md) |
| Install, verify, or build figures | [Development](development.md) |
| Read the paper or render PDF and HTML | [Manuscript index](manuscript/README.md) and [pinned render commands](development.md#render-and-validate-the-manuscript) |
| Extend the registry | [Extensibility](extensibility.md) |
| Run without other Line Set checkouts | [Standalone operation](standalone.md) |
| Cite the source or prepare a release | [Publication](publication.md) |
| Review earlier decisions and evidence | [Maintenance record](TODO.md), [October 2026 review](reviews/2026-10-20-disposition.md), and [release packets](releases/README.md) |

Start at the [project README](../README.md) for the instrument's place in the
Line Set. The [claim ledger](../data/claim_ledger.yaml) records the evidence
behind the manuscript's derived claims.
