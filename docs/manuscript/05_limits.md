# Limits

Every verdict describes declaration coverage only. The instrument does not
verify that a declared label names something real, does not judge the
quality of what is kept, and does not guarantee that anything survives its
custodians. Digests make silent registry edits visible, not impossible, and
say nothing about whether the content is good.

A nonblank custodian and acknowledgment label establish neither acceptance
nor legal succession. Registry eligibility is weaker than a scoped release
declaration; neither authorizes action. A PARTIAL reading covers matched
accepted items only, and an UNDATED reading makes no dated custody claim.
Original and normalized snapshots bind declarations without proving them.
Digests are not a confidentiality mechanism. The supported input boundary is
finite ordinary containers; arbitrary hostile Python objects are not covered.
Safe malformed-text encoding preserves rejected source identity, not valid
evidence or trustworthy content. Full replay requires retained original
declarations; normalized accepted rows alone cannot reproduce rejections.
Native snapshots are not a general serializer for arbitrary Python producers.

The displayed DOI is retained from the prior archived version. It is not an
assigned identifier for this source revision. Current publication authority
permits GitHub Releases with existing Zenodo hooks active, subject to the
archive checks in `docs/publication.md`; no new DOI is inferred here.
