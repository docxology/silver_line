# releases

Per-release records: notes for `v0.1.0` and `v0.2.0`, plus the v0.2.0 gate,
audit, artifact and rendered-provenance files. These are historical receipts;
a new release adds its own files rather than rewriting theirs.

`v0.3.0.gates.json` retains the original native preparation results and records
the separately exercised current PDF/HTML render, validation, provenance and
visual checks. `v0.3.0.artifacts.json` inventories the current source and
publication deliverables. `v0.3.0.rendered-provenance.json` is the integrated
snapshot receipt; `v0.3.0.producer-input-rendered-provenance.json` preserves the
actual render input at `96a7996fb6b50833bf4d50f7e5eddf45d74d5467`.
Independent final audit, source publication and the author's reserve-first DOI
steps remain separate; no automated check grants custody or transfer permission.
